# Étape 9 — la roue de ping : plan d'implémentation

> **Pour les agents :** sous-skill requis : superpowers:subagent-driven-development (recommandé) ou
> superpowers:executing-plans, tâche par tâche. Les étapes utilisent des cases à cocher (`- [ ]`).

**But :** un joueur maintient le clic droit, choisit une intention parmi quatre, et ses alliés voient
le ping dans le monde, sur la mini-carte et par une flèche en bord d'écran.

**Architecture :** deux messages d'événement (`PING` client → serveur, `PING_SHOWN` serveur → tous),
arbitrés et diffusés immédiatement par la `Session` de `back/src/server.ts`, sans toucher `Room`.
Côté client, `GameClient` tient au plus un ping actif par joueur ; une roue DOM produit les
demandes ; un calque Pixi dessine les marqueurs (monde) et les flèches (écran) ; la mini-carte et
l'audio lisent le même état.

**Pile :** TypeScript, `ws`, Fastify, Pixi.js v8, Vitest (jsdom côté front), Biome.

**Spec :** [`docs/specs/2026-10-15-etape-9-ping.md`](../specs/2026-10-15-etape-9-ping.md)

## Contraintes globales

- **Zéro octet de plus par tick** : rien n'entre dans `SNAPSHOT`.
- `PING: 26`, **6 octets** : `type u8 · intent u8 · x i16 · y i16`.
- `PING_SHOWN: 27`, **7 octets** : `type u8 · playerId u8 · intent u8 · x i16 · y i16`.
- `PING_INTENTS = ['viens', 'danger', 'boss', 'jePrends']` ; l'index est l'identifiant.
- `PING_LIFE_TICKS = 120`, `PING_BURST = 3`, `PING_WINDOW_TICKS = 60`, `PING_DEADZONE_PX = 24`.
- Secteurs (écran, y vers le bas) : haut **danger**, droite **je prends**, bas **viens**,
  gauche **boss** ; zone morte → **viens**.
- Refus **silencieux** côté serveur ; `Room` **n'est pas modifié**.
- Le ping de l'émetteur ne s'affiche qu'à l'annonce `PING_SHOWN`, jamais à la demande.
- Commentaires et messages de commit en français sans accents dans le code (convention du dépôt),
  commits au format conventionnel (`feat(...)`, `test(...)`, `docs: ...`).
- **Discipline des sous-agents** (mémoire du projet) : un sous-agent ne lance **que ses fichiers**
  (`npx vitest run <fichier>`), jamais `npm test`, jamais un banc. Le portique complet est lancé
  par le contrôleur, **seul**, à la tâche 7.
- **Prérequis : un arbre propre.** Au 15 octobre, `front/src/main.ts`, `front/src/net/client.ts`,
  `front/index.html` et d'autres fichiers portent des modifications non committées qui ne sont pas
  de cette étape. Les tâches 3, 4 et 6 font `git add` sur ces fichiers : on ne démarre pas tant que
  ce travail n'est pas committé ou mis de côté, sinon il partirait dans les commits du ping.
- Avant chaque commit : `npx biome check --write <fichiers de la tâche>` (le code du plan n'est pas
  garanti au format Biome ; le hook de commit le refuserait).
- Jamais `pkill -f` : les serveurs de dev de Léo tournent sur 5173 et 3100.

**Écart assumé avec la spec, §6.3.** La spec place les flèches « en `<canvas>` 2D avec le reste du
HUD ». Vérification faite, le HUD est en **DOM**, pas en canevas ; seule la mini-carte est un
canevas. Les flèches vont donc dans un calque Pixi **en coordonnées écran**, posé sur `app.stage`
au-dessus de `#world` (comme la secousse de caméra). La fonction pure de placement reste la même et
reste testée sans DOM.

## Points de vigilance de la revue

1. **Un ping reçu pendant le gel de l'étalage** : `hordeTick` n'avance plus, le ping doit rester
   affiché et ne pas expirer d'un coup à la reprise (il expire `PING_LIFE_TICKS` après sa
   réception, en ticks de horde) → test tâche 3.
2. **Un ping d'un joueur parti** : son entrée dans le compteur anti-spam doit être oubliée à la
   déconnexion, et un nouvel arrivant qui récupère l'id ne doit pas hériter de sa fenêtre → test
   tâche 2.
3. **Une trame `PING` tronquée** (moins de 6 octets) : elle ferme cette socket-là, jamais le salon,
   comme toute trame illisible → test tâche 1 (le décodage lève) et le comportement serveur
   existant.
4. **Des coordonnées négatives ou au-delà de `MAP_SIZE`** envoyées par un client : elles arrivent
   bornées dans `[0, MAP_SIZE]` → test tâche 2.
5. **La roue ouverte quand l'étalage s'ouvre ou que la fenêtre perd le focus** : elle se ferme sans
   rien envoyer → test tâche 4.

```ts
/**
 * C -> S : le joueur pose un ping (etape 9), 6 octets.
 *
 * `type u8 · intent u8 · x i16 · y i16`
 *
 * ⚠️ **Un evenement, jamais un etat** : rien n'entre dans `SNAPSHOT`. L'intention
 * n'est PAS validee ici — le decodage rend ce que le fil porte, et c'est le salon
 * qui refuse une intention hors de `PING_INTENTS`.
 */
export interface PingMessage {
  type: typeof MSG.PING;
  intent: number;
  x: number;
  y: number;
}

/** S -> C : le salon annonce un ping accepte, a tous, emetteur compris (etape 9), 7 octets. */
export interface PingShownMessage {
  type: typeof MSG.PING_SHOWN;
  playerId: number;
  intent: number;
  x: number;
  y: number;
}

export const PING_BYTES = 6;
export const PING_SHOWN_BYTES = 7;

export function encodePing(intent: number, x: number, y: number): ArrayBuffer {
  const buf = new ArrayBuffer(PING_BYTES);
  const v = new DataView(buf);
  v.setUint8(0, MSG.PING);
  v.setUint8(1, intent);
  v.setInt16(2, Math.round(x), true);
  v.setInt16(4, Math.round(y), true);
  return buf;
}

function decodePing(buf: ArrayBuffer): PingMessage {
  const v = viewOf(buf, PING_BYTES);
  return {
    type: MSG.PING,
    intent: v.getUint8(1),
    x: v.getInt16(2, true),
    y: v.getInt16(4, true),
  };
}

export function encodePingShown(
  playerId: number,
  intent: number,
  x: number,
  y: number,
): ArrayBuffer {
  const buf = new ArrayBuffer(PING_SHOWN_BYTES);
  const v = new DataView(buf);
  v.setUint8(0, MSG.PING_SHOWN);
  v.setUint8(1, playerId);
  v.setUint8(2, intent);
  v.setInt16(3, Math.round(x), true);
  v.setInt16(5, Math.round(y), true);
  return buf;
}

function decodePingShown(buf: ArrayBuffer): PingShownMessage {
  const v = viewOf(buf, PING_SHOWN_BYTES);
  return {
    type: MSG.PING_SHOWN,
    playerId: v.getUint8(1),
    intent: v.getUint8(2),
    x: v.getInt16(3, true),
    y: v.getInt16(5, true),
  };
}
```

```ts
import type { AddressInfo } from 'node:net';
import { MAP_SIZE } from '@shared/constants';
import { PING_INTENTS } from '@shared/ping';
import {
  decode,
  encodeHello,
  encodePing,
  encodeStart,
  type Message,
  MSG,
} from '@shared/protocol';
import { afterEach, beforeEach, describe, expect, it } from 'vitest';
import { WebSocket } from 'ws';

import * as accounts from './accounts';
import { buildServer } from './server';

/**
 * Le livrable de l'etape 9 : **le ping de A arrive chez A et chez B**, avec la
 * bonne intention et la bonne position, et le salon coupe le spam. Vraies
 * sockets, observe a travers le DECODAGE uniquement.
 */

type App = Awaited<ReturnType<typeof buildServer>>;
type PingShown = Extract<Message, { type: typeof MSG.PING_SHOWN }>;

let app: App;
let port: number;
const sockets: WebSocket[] = [];

beforeEach(async () => {
  await accounts.prisma.account.deleteMany();
  app = await buildServer({ roomSeed: 1, waitingRoom: true });
  await app.listen({ port: 0, host: '127.0.0.1' });
  port = (app.server.address() as AddressInfo).port;
});

afterEach(async () => {
  for (const ws of sockets.splice(0)) {
    ws.close();
  }
  await app.close();
});

async function entre(code: string): Promise<{ ws: WebSocket; recus: Message[] }> {
  const { token } = await accounts.createAccount();
  const ws = new WebSocket(`ws://127.0.0.1:${port}/ws?room=${code}`);
  ws.binaryType = 'arraybuffer';
  sockets.push(ws);
  const recus: Message[] = [];
  ws.on('message', (data: ArrayBuffer) => recus.push(decode(data)));
  await new Promise((res) => ws.once('open', res));
  ws.send(encodeHello(token));
  return { ws, recus };
}

async function jusqua<T>(lire: () => T | undefined): Promise<T> {
  for (let i = 0; i < 150; i++) {
    const v = lire();
    if (v !== undefined) {
      return v;
    }
    await new Promise((r) => setTimeout(r, 20));
  }
  throw new Error('rien recu');
}

const pings = (recus: Message[]): PingShown[] =>
  recus.filter((m): m is PingShown => m.type === MSG.PING_SHOWN);

/** Deux joueurs dans un salon lance : l'hote (id 1) et l'invite (id 2). */
async function partieADeux() {
  const res = await app.inject({ method: 'POST', url: '/rooms' });
  const salon = res.json<{ code: string }>().code;
  const hote = await entre(salon);
  await jusqua(() => hote.recus.find((m) => m.type === MSG.LOBBY));
  const invite = await entre(salon);
  await jusqua(() => invite.recus.find((m) => m.type === MSG.LOBBY));
  hote.ws.send(encodeStart());
  await jusqua(() => invite.recus.find((m) => m.type === MSG.WELCOME));
  return { salon, hote, invite };
}

describe('etape 9 : le salon arbitre et diffuse les pings', () => {
  it('le ping de l invite arrive chez les deux, intention et position intactes', async () => {
    const { hote, invite } = await partieADeux();
    invite.ws.send(encodePing(PING_INTENTS.indexOf('danger'), 1200, 3400));
    const chezHote = await jusqua(() => pings(hote.recus)[0]);
    const chezInvite = await jusqua(() => pings(invite.recus)[0]);
    const attendu = { type: MSG.PING_SHOWN, playerId: 2, intent: 1, x: 1200, y: 3400 };
    expect(chezHote).toEqual(attendu);
    expect(chezInvite).toEqual(attendu);
  });

  it('le quatrieme ping en moins de deux secondes est coupe, puis ca repasse', async () => {
    const { hote, invite } = await partieADeux();
    for (let i = 0; i < 4; i++) {
      invite.ws.send(encodePing(0, 100 + i, 100));
    }
    // Sentinelle : un ping de l'HOTE, dont le compteur est independant. Quand il
    // est arrive, les quatre de l'invite ont ete traites (une seule socket par
    // joueur, ordre garanti par TCP — mais deux sockets ne le sont pas entre
    // elles : on attend donc aussi le troisieme de l'invite).
    hote.ws.send(encodePing(0, 9, 9));
    await jusqua(() => (pings(hote.recus).some((p) => p.playerId === 1) ? true : undefined));
    await jusqua(() =>
      pings(hote.recus).filter((p) => p.playerId === 2).length >= 3 ? true : undefined,
    );
    await new Promise((r) => setTimeout(r, 150));
    expect(pings(hote.recus).filter((p) => p.playerId === 2).map((p) => p.x)).toEqual([
      100, 101, 102,
    ]);

    // Passe la fenetre (2 s de ticks de salon), le meme joueur repasse.
    await new Promise((r) => setTimeout(r, 2100));
    invite.ws.send(encodePing(0, 555, 100));
    await jusqua(() => pings(hote.recus).find((p) => p.x === 555));
  }, 10_000);

  it('une intention inconnue n arrive jamais', async () => {
    const { hote, invite } = await partieADeux();
    invite.ws.send(encodePing(PING_INTENTS.length, 10, 10));
    invite.ws.send(encodePing(0, 77, 77)); // sentinelle, valide
    await jusqua(() => pings(hote.recus).find((p) => p.x === 77));
    expect(pings(hote.recus)).toHaveLength(1);
  });

  it('une position hors carte arrive bornee', async () => {
    const { hote, invite } = await partieADeux();
    invite.ws.send(encodePing(0, -500, MAP_SIZE + 3000));
    const p = await jusqua(() => pings(hote.recus)[0]);
    expect({ x: p.x, y: p.y }).toEqual({ x: 0, y: MAP_SIZE });

  it('rien ne passe en salle d attente', async () => {
    const res = await app.inject({ method: 'POST', url: '/rooms' });
    const salon = res.json<{ code: string }>().code;
    const hote = await entre(salon);
    await jusqua(() => hote.recus.find((m) => m.type === MSG.LOBBY));
    hote.ws.send(encodePing(0, 10, 10));
    await new Promise((r) => setTimeout(r, 200));
    expect(pings(hote.recus)).toHaveLength(0);
  });

  it('un joueur qui revient sur le meme id ne recupere pas la fenetre du precedent', async () => {
    const { salon, hote, invite } = await partieADeux();
    for (let i = 0; i < 3; i++) {
      invite.ws.send(encodePing(0, 200 + i, 10));
    }
    await jusqua(() =>
      pings(hote.recus).filter((p) => p.playerId === 2).length === 3 ? true : undefined,
    );
    invite.ws.close();
    await new Promise((r) => setTimeout(r, 150));
    const retour = await entre(salon);
    await jusqua(() => retour.recus.find((m) => m.type === MSG.WELCOME));
    retour.ws.send(encodePing(0, 999, 10));
    const p = await jusqua(() => pings(hote.recus).find((q) => q.x === 999));
    expect(p.playerId).toBe(2);
  });
});
```

```ts
      // tenir face a `DEATHS` (§5 de la spec de l'etape 9).

        return;

      const now = this.room.tick;
      const recents = (this.#pings.get(id) ?? []).filter((t) => now - t < PING_WINDOW_TICKS);
      if (recents.length >= PING_BURST) {
        this.#pings.set(id, recents);
        return;
      }
      recents.push(now);
      this.#pings.set(id, recents);
      this.#send(encodePingShown(id, msg.intent, clampToMap(msg.x), clampToMap(msg.y)));
      return;
    }
```

```ts
import { PING_INTENTS } from '@shared/ping';

/** Rayon, en pixels ecran, sous lequel un relachement compte comme un clic bref. */
export const PING_DEADZONE_PX = 24;

const VIENS = PING_INTENTS.indexOf('viens');
const DANGER = PING_INTENTS.indexOf('danger');
const BOSS = PING_INTENTS.indexOf('boss');
const JE_PRENDS = PING_INTENTS.indexOf('jePrends');

/**
 * Le secteur vise par le vecteur centre -> curseur, en coordonnees ECRAN (y vers
 * le bas). Quatre secteurs de 90 degres ; une diagonale exacte tombe sur l'axe
 * vertical. Dans la zone morte : un clic bref, donc « viens » (§2 de la spec).
 */
export function pingSectorAt(dx: number, dy: number): number {
  if (Math.hypot(dx, dy) < PING_DEADZONE_PX) {
    return VIENS;
  }
  if (Math.abs(dx) > Math.abs(dy)) {
    return dx > 0 ? JE_PRENDS : BOSS;
  }
  return dy < 0 ? DANGER : VIENS;
}

export interface PingWheelOptions {
  element: HTMLElement;
  canOpen: () => boolean;
  toWorld: (sx: number, sy: number) => { x: number; y: number };
  onPing: (intent: number, x: number, y: number) => void;
  events?: EventTarget;
}

/**
 * La roue de ping : clic droit maintenu, glisser, relacher (§2 de la spec de
 * l'etape 9). Le ping part a la position MONDE de l'ouverture — on vise d'abord,
 * on choisit ensuite. Toute fermeture autre qu'un relachement n'envoie rien.
 */
export class PingWheel {
  readonly #opts: PingWheelOptions;
  #center: { sx: number; sy: number; x: number; y: number } | null = null;

  constructor(opts: PingWheelOptions) {
    this.#opts = opts;
    const events = opts.events ?? window;
    events.addEventListener('pointerdown', (e) => this.#down(e as MouseEvent));
    events.addEventListener('pointerup', (e) => this.#up(e as MouseEvent));
    events.addEventListener('blur', () => this.#close());
  }

  get isOpen(): boolean {
    return this.#center !== null;
  }

  update(): void {
    if (this.#center && !this.#opts.canOpen()) {
      this.#close();
    }
  }

  #down(e: MouseEvent): void {
    if (e.button !== 2 || !this.#opts.canOpen()) {
      return;
    }
    const world = this.#opts.toWorld(e.clientX, e.clientY);
    this.#center = { sx: e.clientX, sy: e.clientY, x: world.x, y: world.y };
    const el = this.#opts.element;
    el.style.left = `${e.clientX}px`;
    el.style.top = `${e.clientY}px`;
    el.classList.remove('hidden');
  }

  #up(e: MouseEvent): void {
    const c = this.#center;
    if (e.button !== 2 || !c) {
      return;
    }
    this.#close();
    this.#opts.onPing(pingSectorAt(e.clientX - c.sx, e.clientY - c.sy), c.x, c.y);
  }

  #close(): void {
    this.#center = null;
    this.#opts.element.classList.add('hidden');
  }
}
```

> `toWorld` reçoit des coordonnées **client** (`clientX/Y`). Dans `main.ts`, on les convertit en
> coordonnées relatives au canevas avant `stage.screenToWorld`, exactement comme `Mouse` le fait
> (`clientX - rect.left`).

```ts
import { PING_INTENTS, PING_LIFE_TICKS } from '@shared/ping';
import { type Container, Graphics } from 'pixi.js';

import type { ActivePing } from '../net/client';

/** Un ping a dessiner a cette image. */
export interface LivePing {
  playerId: number;
  intent: number;
  x: number;
  y: number;
  /** Opacite, `1` puis s'efface sur le dernier quart de sa vie. */
  alpha: number;
  /** Rayon de l'onde, en pixels monde. */
  wave: number;
}

const WAVE_MIN = 18;
const WAVE_MAX = 90;

/**
 * Les pings vivants au tick de horde `tick`. Le tick, jamais l'horloge murale :
 * pendant le gel de l'etalage il n'avance pas, et un ping recu juste avant ne
 * doit pas s'eteindre pendant que personne ne peut le lire.
 */
export function livePings(pings: ReadonlyMap<number, ActivePing>, tick: number): LivePing[] {
  const out: LivePing[] = [];
  for (const p of pings.values()) {
    const age = tick - p.tick;
    if (age < 0 || age >= PING_LIFE_TICKS) {
      continue;
    }
    const t = age / PING_LIFE_TICKS;
    const restant = 1 - t;
    out.push({
      playerId: p.playerId,
      intent: p.intent,
      x: p.x,
      y: p.y,
      alpha: restant > 0.25 ? 1 : restant / 0.25,
      wave: WAVE_MIN + ((age % 30) / 30) * (WAVE_MAX - WAVE_MIN),
    });
  }
  return out;
}

export interface EdgeArrow {
  x: number;
  y: number;
  /** Direction centre -> cible, en radians (`atan2`, y vers le bas). */
  angle: number;
}

/**
 * Ou poser la fleche d'une cible hors champ, en coordonnees ECRAN. `null` si la
 * cible est dans le rectangle de la vue reduit de `margin` : elle se voit deja.
 * Sinon, le point ou le segment centre -> cible sort de ce rectangle.
 */
export function edgeArrow(
  w: number,
  h: number,
  tx: number,
  ty: number,
  margin: number,
): EdgeArrow | null {
  const cx = w / 2;
  const cy = h / 2;
  const hw = cx - margin;
  const hh = cy - margin;
  const dx = tx - cx;
  const dy = ty - cy;
  if (Math.abs(dx) <= hw && Math.abs(dy) <= hh) {
    return null;
  }
  const k = Math.min(dx === 0 ? Infinity : hw / Math.abs(dx), dy === 0 ? Infinity : hh / Math.abs(dy));
  return { x: cx + dx * k, y: cy + dy * k, angle: Math.atan2(dy, dx) };
}

/** Taille d'une fleche d'allie : `1` pres, `0.5` au-dela de 4000 px monde. */
export function allyArrowScale(distance: number): number {
  return Math.max(0.5, 1 - distance / 8000);
}

const MARGIN = 28;
const DANGER = PING_INTENTS.indexOf('danger');
const BOSS = PING_INTENTS.indexOf('boss');
const JE_PRENDS = PING_INTENTS.indexOf('jePrends');

/** L'icone d'une intention, centree sur (x, y). Une forme par intention, lisible sans texte. */
function intentIcon(g: Graphics, intent: number, x: number, y: number, r: number, color: number, alpha: number): void {
  if (intent === DANGER) {
    g.poly([x, y - r, x + r, y + r * 0.8, x - r, y + r * 0.8]).fill({ color: 0xff4a3a, alpha });
    g.poly([x, y - r, x + r, y + r * 0.8, x - r, y + r * 0.8]).stroke({ color, width: 2, alpha });
  } else if (intent === BOSS) {
    g.poly([x, y - r, x + r, y, x, y + r, x - r, y]).fill({ color, alpha });
  } else if (intent === JE_PRENDS) {
    g.rect(x - r * 0.8, y - r * 0.8, r * 1.6, r * 1.6).fill({ color, alpha });
  } else {
    g.circle(x, y, r).fill({ color, alpha });
  }
}

/**
 * Le calque des pings (etape 9) : un `Graphics` dans le MONDE pour les
 * marqueurs, un autre en coordonnees ECRAN pour les fleches de bord.
 */
export class PingRenderer {
  readonly #world = new Graphics();
  readonly #screen = new Graphics();
  #ready = false;

  constructor(private readonly colorOf: (playerId: number) => number) {}

  attach(parent: Container): void {
    parent.addChild(this.#world);
  }

  /** Le calque ecran se pose sur `app.stage`, au-dessus du monde (voir `Stage.init`). */
  attachScreen(parent: Container): void {
    parent.addChild(this.#screen);
  }

  get loaded(): boolean {
    return this.#ready;
  }

  load(): void {
    this.#ready = true;
  }

  draw(
    pings: readonly LivePing[],
    allies: readonly { id: number; x: number; y: number; distance: number }[],
    toScreen: (x: number, y: number) => { x: number; y: number },
    w: number,
    h: number,
  ): void {
    const g = this.#world;
    const s = this.#screen;
    g.clear();
    s.clear();
    for (const p of pings) {
      const color = this.colorOf(p.playerId);
      g.circle(p.x, p.y, p.wave).stroke({ color, width: 3, alpha: p.alpha * (1 - p.wave / 120) });
      intentIcon(g, p.intent, p.x, p.y - 34, 12, color, p.alpha);
      g.moveTo(p.x, p.y - 22).lineTo(p.x, p.y).stroke({ color, width: 2, alpha: p.alpha });
      const sp = toScreen(p.x, p.y);
      const a = edgeArrow(w, h, sp.x, sp.y, MARGIN);
      if (a) {
        drawArrow(s, a, 1.2, color, p.alpha);
        intentIcon(s, p.intent, a.x - Math.cos(a.angle) * 26, a.y - Math.sin(a.angle) * 26, 9, color, p.alpha);
      }
    }
    for (const ally of allies) {
      const sp = toScreen(ally.x, ally.y);
      const a = edgeArrow(w, h, sp.x, sp.y, MARGIN);
      if (a) {
        drawArrow(s, a, allyArrowScale(ally.distance), this.colorOf(ally.id), 0.85);
      }
    }
  }
}

function drawArrow(g: Graphics, a: EdgeArrow, scale: number, color: number, alpha: number): void {
  const L = 16 * scale;
  const c = Math.cos(a.angle);
  const s = Math.sin(a.angle);
  // Un triangle dont la pointe est sur le bord, vers la cible.
  g.poly([
    a.x, a.y,
    a.x - L * c + L * 0.6 * s, a.y - L * s - L * 0.6 * c,
    a.x - L * c - L * 0.6 * s, a.y - L * s + L * 0.6 * c,
  ]).fill({ color, alpha });
}
```

```ts
  /** Coordonnees MONDE -> ECRAN, la reciproque exacte de `screenToWorld`. */
  worldToScreen(x: number, y: number): { x: number; y: number } {
    return { x: x + this.#world.x, y: y * VERTICAL_SQUASH + this.#world.y };
  }

  drawPings(
    pings: ReadonlyMap<number, ActivePing>,
    players: readonly { id: number; x: number; y: number }[],
    localId: number | null,
    tick: number,
    _timeMs: number,
  ): void {
    const me = players.find((p) => p.id === localId);
    const allies = me
      ? players
          .filter((p) => p.id !== localId)
          .map((p) => ({ id: p.id, x: p.x, y: p.y, distance: Math.hypot(p.x - me.x, p.y - me.y) }))
      : [];
    this.#pings.draw(
      livePings(pings, tick),
      allies,
      (x, y) => this.worldToScreen(x, y),
      this.#app.screen.width,
      this.#app.screen.height,
    );
  }
```
